Protein Quantification Calculator

Paste absorbance readings to build a standard curve, quantify samples, and plan loading volumes.

STD raw data

Each Abs row is one STD point, in the order entered; replicates go across columns (1 column → n = 1, 2 columns → n = 2). Enter STD conc vertically in the same order; if blank, 0, 0.031, 0.063, 0.125, 0.25, 0.5, 1 are used.

Sample raw data

Each row is one sample, named Sample 1, 2, … in the order entered. Replicates of the same sample go across columns: 1 column → n = 1, 2 columns → n = 2.
